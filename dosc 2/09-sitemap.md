# 09 - Sitemap BSIS

Sitemap merupakan gambaran struktur halaman pada sistem BSIS yang
dikelompokkan berdasarkan jenis pengguna.

## A. Public Website
- Beranda
- Tentang Pesantren
- Program Pendidikan
- Fasilitas
- Berita dan Pengumuman
- Galeri
- Kontak
- Informasi PPDB
- Login

## B. Applicant Portal
- Dashboard Pendaftar
- Formulir Pendaftaran
- Upload Dokumen
- Status Pendaftaran
- Informasi Daftar Ulang

## C. Internal Dashboard
- Dashboard Admin
- Manajemen Pendaftar
- Manajemen Data Santri
- Manajemen Keuangan
- Manajemen Uang Jajan
- Manajemen Konten
- Laporan
- Manajemen Pengguna

## D. Parent Portal
- Dashboard Orang Tua
- Profil Santri
- Informasi Akademik
- Informasi Kepesantrenan
- Tagihan dan Pembayaran
- Saldo Uang Jajan
- Riwayat Mutasi Uang Jajan
- Pengumuman
