# Stakeholder dan Actor/Role Matrix BSIS
## 1. Stakeholder

| Stakeholder | Kepentingan |
|---|---|
| Pimpinan Pesantren | Memantau perkembangan dan laporan pesantren |
| Admin Pesantren | Mengelola administrasi sistem |
| Petugas PPDB | Mengelola pendaftaran calon santri |
| Bagian Akademik | Mengelola informasi akademik |
| Bagian Keuangan | Mengelola tagihan dan pembayaran |
| Orang Tua | Mendapatkan informasi mengenai anak |

## 2. Actor dan Role
| Actor/Role | Tugas |
|---|---|
| Super Admin | Mengelola seluruh konfigurasi utama sistem |
| Admin | Mengelola administrasi |
| PPDB | Mengelola pendaftaran calon santri |
| Academic | Mengelola informasi akademik |
| Boarding | Mengelola informasi kepesantrenan |
| Finance | Mengelola tagihan dan pembayaran |
| Allowance Officer | Mengelola transaksi uang jajan |
| Parent | Melihat informasi santri yang menjadi tanggung jawabnya |
